# Google Play「数据安全」表单填写对照

本文件把应用的真实行为映射到 Play Console 的 Data safety 问题。**提交前请以 Play Console 当天的措辞为准**，并确保与 [privacy.html](privacy.html)、[PRIVACY.md](PRIVACY.md) 完全一致。

## 一、总体回答

| 问题 | 回答 | 依据 |
|---|---|---|
| 应用是否收集或共享任何必填用户数据类型？ | **是**（可选功能触发时） | 见下表 |
| 所有用户数据在传输中是否加密？ | **是** | `HttpJson` 强制 HTTPS，明文 HTTP 被拒绝 |
| 是否提供数据删除方式？ | **不适用（无账号）** | 本地删除/卸载即可；无服务端副本 |
| 是否遵循 Play 的家庭政策？ | **否** | 目标人群 18+ |
| 是否包含广告？ | **否** | 无广告 SDK |
| 是否包含应用内购买？ | **否**（当前版本） | 无计费 |

## 二、数据类型明细

| Play 数据类别 | 是否涉及 | 场景 | 收集/共享 | 用途 | 是否可选 | 处理方式 |
|---|---|---|---|---|---|---|
| 位置 → 大致位置 | 是 | 查询天气 | 共享给 Open-Meteo | 应用功能 | 是（拒绝则用默认城市） | 不存储；仅经纬度 |
| 照片和视频 → 照片 | 是 | 版型识别 | 共享给用户配置的视觉服务 | 应用功能 | 是（逐次确认） | 本地缩放/去 EXIF 后上传，开发者不保存 |
| 应用活动 → 应用内搜索历史 / 其他用户生成内容 | 是（建议按此申报） | AI 对话文本 | 共享给用户配置的对话服务 | 应用功能 | 是（需自备 Key） | 仅当前会话内存，开发者不保存 |
| 个人信息（姓名/邮箱/电话） | 否 | 无账号 | — | — | — | — |
| 财务信息 | 否 | 无支付 | — | — | — | — |
| 健康与健身 | 否 | — | — | — | — | — |

## 三、安全实践

| 问题 | 回答 | 依据 |
|---|---|---|
| 数据是否加密传输？ | 是 | 全部请求 HTTPS；明文 HTTP 在 `HttpJson` 被拒绝 |
| 是否遵循 Play 的「数据删除」要求？ | 不适用 | 无账号，无服务端数据 |
| 是否经过独立安全审查？ | 否 | 个人项目，未做第三方审计 |
| 是否使用数据做广告/个性化？ | 否 | 无广告、无画像 |
| 是否允许用户请求删除数据？ | 本地删除即可 | 应用内删除单品/打卡/日程；卸载清除全部数据 |

## 四、第三方 SDK 说明

| SDK | 是否收集数据 | 说明 |
|---|---|---|
| ML Kit 图像打标 | 否 | 模型与推理在设备本地，不联网 |
| LiteRT-LM（本地专家） | 否 | 纯本地推理 |
| AndroidX / Compose / Room / WorkManager | 否 | 系统库 |
| Open-Meteo | 接收坐标 | 第三方天气服务，仅查询天气 |
| 用户配置的视觉/对话服务 | 接收照片/文本 | 由用户自行配置，按该服务商条款处理 |
| Hugging Face | 接收下载请求 | 仅下载模型文件，不上传用户数据 |
